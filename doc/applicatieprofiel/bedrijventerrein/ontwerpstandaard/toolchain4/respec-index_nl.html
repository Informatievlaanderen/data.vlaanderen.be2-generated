Bedrijventerrein

URI
https://data.vlaanderen.be/ns/bedrijventerrein#Bedrijventerrein
Definition
Som van alle ruimtelijke eenheden uit de ruimtelijke planningsprocedure en met een economische bestemming vanaf de dossierfase Publicatie in Belgisch Staatsblad. Een bedrijventerrein is altijd de unie van de percelen die ertoe behoren.
Property Type Definition Cardinality
beschikbare kavels http://www.w3.org/2001/XMLSchema#boolean Deze eigenschap geeft aan of er al dan niet beschikbare kavels aanwezig zijn op het bedrijventerrein.
beschikbare oppervlakte https://schema.org/QuantitativeValue Deze eigenschap geeft aan hoeveel oppervlakte nog beschikbaar is op het bedrijventerrein.
is gerelateerd aan economisch gebied https://data.vlaanderen.be/ns/bedrijventerrein#EconomischGebied Economisch Gebied waarmee het bedrijventerrein kan geassocieerd worden.

Economisch Gebied

URI
https://data.vlaanderen.be/ns/bedrijventerrein#EconomischGebied
Definition
Een economisch gebied is een gebied dat afgebakend wordt op basis van dichtheid van hoofdzakelijk bebouwde percelen met economische activiteiten, waarbij de dichtheid wordt uitgedrukt in nabijheid of de afstand tussen deze percelen. De afstand tussen deze percelen, de mix van economische activiteiten en het voorkomen van een gedeelde infrastructuur zijn bepalend voor de differentiatie tussen de types economische gebieden.
Property Type Definition Cardinality
dominante economische activiteit http://www.w3.org/2004/02/skos/core#Concept De voornaamste economische activiteit dat geassocieerd kan worden met het Economisch Gebied
is gerelateerd aan economisch gebied https://data.vlaanderen.be/ns/bedrijventerrein#Bedrijventerrein Economisch Gebied waarmee het bedrijventerrein kan geassocieerd worden.

Ontwikkelbare Bedrijvenzone
