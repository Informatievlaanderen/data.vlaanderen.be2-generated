Gebouw

Gebouweenheid

URI
https://data.vlaanderen.be/ns/gebouw#Gebouweenheid
Definition
De kleinste eenheid binnen een gebouw die geschikt is voor woon-, bedrijfsmatige, of recreatieve doeleinden en die ontsloten wordt via een eigen afsluitbare toegang vanaf de openbare weg, een erf of een gedeelde circulatieruimte. Een gebouweenheid is in functioneel opzicht zelfstandig. Daarnaast kan een gebouweenheid ook een gemeenschappelijk deel zijn.
Property Type Definition Cardinality
adres http://www.w3.org/ns/locn#Address Adresvoorstelling die bij de gebouweenheid hoort.

gebouweenheidstatus http://www.w3.org/2004/02/skos/core#Concept Fase van de levensloop waarin de gebouweenheid zich bevindt.
geometrie http://www.w3.org/ns/locn#Geometry 2D-geometrische voorstelling van de gebouweenheid.
