This document describes an application profile, in this case Applicatieprofiel Hydrants. The application profile specifies a semantic data model covering a set of usecases. The specification consists of terms with their constraints (cardinalities, codelists, usage guidelines).

Summary

The model presented below is an application profile of the theme ‘Hydrants’, built in the context of the ICEG thematic working group, regrouping experts from the federal and regional level as well as communities. The model was designed through a series of workshops and a final open consultation.

The objective was to standardize the terms defined for hydrants at regional and federal level, starting from the stakeholders' requirements, and relying on OSLO and SAREF. It serves the purpose to make data accessible as linked open data and to define standard interfaces (APIs) to simplify interprovincial and interregional collaboration and integration of the various services and tools.

The Hydrant Vocabulary is designed to support the exchange of basic information about hydrants. Using the vocabulary will make it easier for institutions to publish data concerning this theme.

Used (external) terminology

This section provides an overview of how terminology from vocabularies is used in this application profile.

This application profile relies on terms from these proprietary vocabularies:

For terms from vocabularies outside the namespace data.vlaanderen.be takes the form of a mapping: for the terms listed in this section, it was decided to use a term identifier (the URI) from vocabularies that do not fall under the management of Data.vlaanderen.be.

This form of reuse is agreeing to the underlying definition, labels and restrictions associated with the URI in the context of this application profile. This means that the above definitions, labels and usage notes should not contradict those of the URI.

However, this mapping is a choice valid for this application profile. But it is a strong suggestion to also apply this mapping in other, related domains. A change to the mapping is not a semantic change of the application profile, but it may have a major implementation impact. The impact can be described clearly and unambiguously with the mapping below.

Note that the need to implement a mapping change often also entails semantic adjustments. Therefore, it is advisable to include changes in the normal change management of the standard.
