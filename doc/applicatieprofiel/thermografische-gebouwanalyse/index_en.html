This document describes an application profile, in this case Application profile Thermographic Building Analysis. The application profile specifies a semantic data model covering a set of usecases. The specification consists of terms with their constraints (cardinalities, codelists, usage guidelines).

Summary

This application profile can be used to describe the results and intermediate results of the step-by-step process of making, processing and interpreting thermographic scans of buildings .

It was developed as part of thermographic building analysis projects, in which a vehicle equipped with a thermographic camera scans building facades to identify areas of energy loss. This data is then processed to provide homeowners with targeted renovation advice. Instead of time-consuming manual data processing, automatic processing by means of AI is now being pursued.

To capture the actual Observation and associated information about the Observation Procedure, the Observable Feature, the observed Object and the Sensor, classes from the internationally recognized Semantic Sensor Network Ontology (SSNO), tailored to ISO19156, were used. An Observation is performed with a Sensor and more specifically for thermographic scans with a thermographic Camera and GNSS Receiver in a given Setup. These are provided as subclasses of Sensor in addition to MachineLearningModel, a class from MLDCAT-AP that can be used to describe the AI model if it has been used for the interpretation of the images.

With the exception of image calibration, each step in the process can be represented by an instance of the Observation class, ranging from the actual recording of the video, the extraction of a specific localized frame from it, the identification of the façade elements in that frame to the determination of the heat loss of an element and its classification. This is how we arrive at an advice on heat loss in a building consisting of a set of classifications of façade elements, combined in an Observation Collection.

The Objects that are observed are the roads or streets that were filmed with the thermographic camera (not explicitly in the model), the Video that results from it, the localized frame from it (represented by an object of the type Photo), the Building or Building Unit that corresponds to the frame and its façade elements whose individual heat loss will be determined and classified.

Video and Photo can be described as Information Objects (a class from CIDOC-CRM) and their subclasses provided for such objects in LRM (see also OSLO Cultural Heritage and OSLO Cultural Heritage Key Registration). Building and Building Unit are classes from OSLO Building and for the façade elements we use classes BIM_Gebouw and BIM_Element from the Industry foundation Classes (IFC) and the corresponding ontology.

For more information about the concrete use of this standard, we refer to detailed data examples per process step in github or in the modelling report.
