This document describes an implementation model, in this case Customer Tracking System Release 1 Deployment Model. This implementation model answers the question of how the corresponding domain model can be applied in practice. It explains the constraints (cardinality, code lists) and lists the corresponding (RDF) terms.

Summary

Customer Monitoring System is an implementation model that allows the exchange of data about trajectories at VDAB and its partners to ensure the follow-up of job seekers.

Status of this document

This implementation model has the status Ontwerp Standaard and was published on 2025-11-04.

In case law, it concerns a person (in the legal sense, i.e. with its own legal personality) of the human species, i.e. a physical person. Counterpart is the legal entity, a legal construction that gives a private or public organization the same legal personality as a natural person (e.g. can also have debts, conclude contracts, be sued, etc.).

The service constitutes an offer (which is therefore not necessarily used). It does not necessarily imply the inclusion of a right, the service may also allow the user to fulfil an obligation.

PublicOrganization

Description
An Organisation that belongs to the public sector according to a legal framework, regardless of the level of government at which that framework is in force.
Usage
The public and semi-public organisations that can be classified as public sector are referred to in European Directive 2003/98/EC as "public bodies" and defined as: "the State, regional or local authorities, bodies governed by public law, associations formed by one or more of such bodies or one or more of such bodies governed by public law". And a body governed by public law means 'any body which (a) has been established for the specific purpose of meeting needs in the general interest, not having an industrial or commercial character, and (b) has legal personality, and (c) the activities of which are financed, for the most part, by the State, regional or local authorities or by other bodies governed by public law, either the management is subject to supervision by the latter, or more than half of the members of the administrative, managerial or supervisory board are appointed by the State, regional or local authorities or other bodies governed by public law.';

Registered Person

Description
Person whose data is registered in a register.
Usage
Usually this register is a population register, but it can also be an electoral register, for example. The registered data relate to the identity (e.g. surname and first name) and the place of residence of the person and to important life events such as birth, marriage, death, etc. These data are typically recorded by the government, they provide legal protection to the registered person and allow the government to compile basic statistics on its population.

Datatypes

Address presentation

Description
More readable presentation with only the basic data of the address, intended for the use of an address as an attribute of another object.
Usage
For example, as an attribute of a person or building, ... The address presentation does not only relate to Belgian addresses, it can be used to represent foreign addresses (where possible address indications other than house number or box number are used or where address components such as address areas occur).
Properties
The following properties are defined for this datatype: Box number , Country , House number , Municipality name , Post Name , Postal code , street name .
Property Expected Type Cardinality Description Usage Codelist
Box number String 0..1 Officially assigned alphanumeric code that is added to the house number to distinguish several building units, pitches, berths or plots that have the same house number. Specialization of Address Presentation: location indication for Belgian addresses.
Country LangString 0..1 Country in which the address is located.
House number String 0..1 Alphanumeric code officially assigned to building units, berths, stands or plots. Specialization of Address Presentation: location indication for Belgian addresses.
Municipality name LangString 0..1 Municipality name of the address.
Post Name LangString 0..1 Name indicating the geographical area that groups addresses for postal purposes.
Postal code String 0..1 Code that identifies the geographical area that groups addresses for postal purposes.
street name LangString 0..1 Street name of the address.
