This document describes an implementation model, in this case Road vignette registration implementation model. This implementation model answers the question of how the corresponding domain model can be applied in practice. It explains the constraints (cardinality, code lists) and lists the corresponding (RDF) terms.

Summary

The MAGDA Road Vignette Registrations Implementation Model is based on the MAGDA Vehicle Registration Implementation Model that in turn relies on Eucaris, the European standard for exchanging vehicle registrations between Member States.

The deployment model reuses several elements of Schema.org where all relevant attributes about vehicles are included that also apply to a registration of a vehicle.

Engine Specification

Description
Information about the engine or engines of a Vehicle.
Usage
An engine specification corresponds to one registered engine in the source and not necessarily to one physical engine. One engine specification can describe a combination of an internal combustion engine and an electric motor, for example in a hybrid vehicle. The number of engine specifications of a vehicle is therefore not a reliable indication of the actual number of engines.
Properties
The following properties are defined for this entity: FuelType , motorType .
Property Expected Type Cardinality Description Usage Codelist
FuelType Fuel type 0..* The type of fuel that is suitable for the vehicle's engine(s). The value comes from the Fuel Type code list, which adopts the IVI fuel codes. An engine specification can have multiple fuel types, for example, gasoline and LPG. Link
motorType Engine type 0..* The type of engine or motors that drive the vehicle. The value comes from the code list Engine type: combustion engine or electric motor. An engine Specification can have multiple engine Types to indicate that one registered engine Specification actually relates to multiple physical engines. Also, the engine type may also be missing if it cannot be deduced from the source. Link

Property Expected Type Cardinality Description Usage Codelist

Registration

Description
Registration of a Vehicle in a national register.
Usage
The Vehicle is given a registration number and is linked to a Person or Organisation (whether or not the owner of the Vehicle). The date from which the registration is valid will be determined. The registration number is displayed on a License plate.
Properties
The following properties are defined for this entity: License plate , vehicle .
Property Expected Type Cardinality Description Usage Codelist
License plate License plate 0..1 A physical medium that contains the registration number of the vehicle under which the vehicle was registered.
vehicle Vehicle 0..1 The vehicle that is linked to the Registration Certificate.

Road vignette registration

Description
Registration of a Vehicle for a road vignette, which entitles the vehicle to use the road network for a certain period of time.
Usage
Refers to the Registration of the Vehicle in the national register.
Properties
The following properties are defined for this entity: hasVehicle registration , registrationDate .
Property Expected Type Cardinality Description Usage Codelist
hasVehicle registration Registration 1 The Registration of the Vehicle to which the Road Vignette Registration applies.
registrationDate Date 0..1 Time at which the Road Vignette Registration was drawn up.

Vehicle

Description
A vehicle is a device designed or used to transport people or cargo by land, water, air, or space.
Properties
The following properties are defined for this entity: emission standard , FirstRegistrationDate , vehicleEngine , Vin .
Property Expected Type Cardinality Description Usage Codelist
emission standard Euro standard 0..1 The emission standard that the Vehicle meets. For example: Euro 6d. The value comes from a code list, so that other or future emission standards than the Euro standard can also be expressed. Link
FirstRegistrationDate Date 0..1 First date on which the vehicle was registered in a register.
vehicleEngine Engine Specification 0..* The engine or engines of the Vehicle.
Vin Identifier 0..1 The Vehicle Identification Number (VIN) is a unique serial number that has been used in the automotive industry to distinguish individual vehicles from each other.
