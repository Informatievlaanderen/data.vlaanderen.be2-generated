Address Representation

URI http://www.w3.org/ns/locn#Address
Definition More readable representation containing only the basic data of the address,intended for using an address as an attribute of another object.
Label Address Representation
Usage note Eg as attribute ve person or building. The address representation does not only refer to Belgian addresses, it can be used to represent foreign addresses (where address designations other than house number or bus number may be used or where address components such as address areas occur).

Label Appurtenance
Usage note Can stand alone as a Utility Node, but is often mounted on a carrier (the Utility Node Container). For example an inspection hatch, a hydrant, a splitter, a meter, a pump etc.
