Besluit

URI http://data.vlaanderen.be/ns/besluit#Besluit
Definition De authentieke schriftelijke neerslag van een beslissing van een bestuursorgaan. Deze beslissing houdt een rechtshandeling in waarbij sprake is van een beoogd rechtsgevolg.
Label Besluit
Usage note Hieronder vallen zowel individuele besluiten (rechtshandelingen met een individueel karakter zoals het toekennen van een subsidie) als besluiten van algemene strekking (beslissingen van algemene reglementaire strekking die niet gericht zijn op een individu maar op een groep, zoals de verkeersregels).
Parent http://xmlns.com/foaf/0.1/Document
http://data.europa.eu/eli/ontology#LegalExpression
http://purl.org/vocab/cpsv#FormalFramework
