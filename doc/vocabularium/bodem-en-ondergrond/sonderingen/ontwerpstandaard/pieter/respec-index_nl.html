DirectePositie

URI https://data.vlaanderen.be/ns/generiek#DirectePositie
Definition Houder van de coördinaten van een positie in een coördinaatreferentiesysteem.
Label DirectePositie
Usage note Typisch gebruikt om de geometrie van een ruimtelijk object te beschrijven of de geometrische primitieven (bijvoorbeeld punt, Lijn, Vlak...) waaruit dat object is samengesteld. Een DirectePositie kan echter ook op zichzelf staan om een positie in de ruimte te beschrijven. De positie wordt gegeven in een coördinaatreferentiesysteem. Dat referentiesysteem wordt expliciet bij de DirectePositie opgegeven, tenzij deze deel uitmaakt van een ruimtelijk object (bijvoorbeeld een geometrische primitieve) waar al een referentiesysteem wordt vermeld. Ter info: Een coördinaatreferentiesysteem verschilt van een indirect ruimtelijk referentiesysteem in die zin dat posities direct door middel van coördinaten worden opgegeven ipv indirect door een adres of plaatsnaam.
