RecordType

URI http://def.isotc211.org/iso19103/2005/RecordsAndClassMetadata#RecordType
Definition A RecordType is a look up mechanism that associates AttributeNames to TypeNames. AttributeNames are locally mapped. TypeNames are most often either primitives, or other types in the same schema as this record. Because the RecordType can control the structure of a set of Records, it is essentially a metaclass for that set of records view as a class. A RecordType is a NameSpace for its included attributeTypes.
Label RecordType
