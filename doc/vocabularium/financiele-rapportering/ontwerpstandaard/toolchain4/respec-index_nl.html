Concept

URI https://data.vlaanderen.be/ns/financiele-rapportering#Concept
Definition Definitie van een type Feit.
Label Concept
Usage note Beschrijving van een financieel begrip waarop een Feit betrekking kan hebben, bvb Activa, Omzet, Kosten etc. De beschrijving omvat zaken zoals de definitie van het Concept, het verwachte datatype (bvb Monetair), de relatie met andere Concepten (Omzet is bvb een subtype Inkomsten). Feit

URI https://data.vlaanderen.be/ns/financiele-rapportering#Feit
Definition Een individueel stuk informatie in een FinancieelRapport.
Label Feit
Usage note Typisch de waarde in valuta van één bepaald financieel kenmerk van een Organisatie (bv Omzet, Kosten etc) beschouwd in een specifieke Context (bvb het huidig boekjaar en Dimensies zoals het Product en/of de Regio waarop het Feit betrekking heeft). Feiten vormen de atomaire onderdelen van het FinancieelRapport, beschouwen we het rapport als een multidimensionele gegevenskubus (zie Hypercube) dan vertegenwoordigt een individueel Feit één cel in die kubus.

Hypercube

URI https://data.vlaanderen.be/ns/financiele-rapportering#Hypercube
Definition Structuur van de gegevenskubus die het FinancieelRaport vormt.
Label Hypercube
Usage note De Feiten in een FinancieelRapport worden gerangschikt zoals in een datawarehouse, ttz in rijen en kolommen zoals in een tabel maar dan een tabel in meer dan twee dimensies: een zgn n-dimensionele gegevenskubus. Concreet wordt hier onder Hypercube een opsomming verstaan van de Dimensies die een Concept kan hebben, het is maw een uitbreiding van het Schema met een Dimensieschema.
