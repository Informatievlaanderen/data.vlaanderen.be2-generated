This document describes a vocabulary, in this case Vocabulary Teaching Resources. A vocabulary is a collection of reusable terms, namely classes and properties, whose meaning is recorded through a label and definition. For terms defined in this domain, additional formal agreements are available. For external terms, the formal agreements are copied from the external source.

Summary

The OSLO Educational Resources vocabulary defines terms that are applicable to the exchange of information about Educational Resources. More specifically, it is about how educational resources can be exchanged internationally, whether or not on the basis of associated goals. Furthermore, the vocabulary also contains the necessary terms about licenses and the (re)use of creative works.

The vocabulary provides an overview of the terminology used and associated definitions.

This vocabulary is used by the application profile OSLO Educational Resources.

Status of this document

This section describes the status of this document at the time of publication. It is possible that newer versions have already been released in the meantime.

This vocabulary has the status Kandidaat Standaard and was issued on 2025-08-01.

This document is an official specification of a vocabulary and provides a shared conceptual framework for certain concepts. This specification serves to clarify the definition, use, domain, and scope of the RDF terms within this domain. The terms defined in this vocabulary are persistent and will therefore never disappear, nor will the definitions change except to further clarify an existing definition. However, terms may be labeled as obsolete and replaced in newer versions of this specification.

1. License

This specification of Informatie Vlaanderen is published under the "Model License Free Reuse - v1.0".

2. Conformity

An exchange of data, by whatever means, is subject to this vocabulary when it uses the terminology (classes and properties) in a manner consistent with the semantics established in the latest version of the specification (domain, scope, definition and usage) and does not use terminology from other vocabularies as an alternative to the proposed terminology included in this vocabulary.

4. Classes

This section provides a formal definition to each class.

Class Competence

Type Class
URI https://data.vlaanderen.be/ns/leermiddelen#Competentie
Definition A specific set of knowledge, skills and attitudes that must be mastered by a learner.

Usage

 In this context, it concerns key competences, scientific domains and professional qualifications.

Status

 https://data.vlaanderen.be/id/concept/StandaardStatus/KandidaatStandaard

Class Learning tool

Type Class
URI https://data.vlaanderen.be/ns/leermiddelen#Leermiddel
Specialization of
  • https://schema.org/CreativeWork
Definition Any tool that is used to support the learning process, achieve goals and thus impart knowledge, skills and attitudes.

Usage

 This definition is a specification based on the definition of the Quality Alliance, i.e.: The umbrella term for both paper and digital products, whether in combination or not, regardless of who develops them: teachers, non-commercial and commercial providers.

Status

 https://data.vlaanderen.be/id/concept/StandaardStatus/KandidaatStandaard

 https://data.vlaanderen.be/id/concept/StandaardStatus/KandidaatStandaard

Type Class

6. External terminology

Since 2025, external terms are no longer included as non-normative mapping in vocabularies of data.vlaanderen.be.

Instead, a table with which external URIs are used has been added to each application profile. This simplifies the objective of this document. Namely listing and managing terms defined in this namespace.

To still achieve harmonization of the use of external terminology, a general mapping is published.
