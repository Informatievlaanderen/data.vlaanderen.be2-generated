Classes

This section gives a formal definition to each class.

Agent

URI http://purl.org/dc/terms/Agent
Definition Someone who or something that can act or bring about an effect.
Label Agent

Competence

URI https://data.vlaanderen.be/ns/leermiddelen#Competentie
Definition A specific set of knowledge, skills and attitudes that must be mastered by a learner.
Label Competence
Usage note In this context, it concerns key competences, scientific domains and professional qualifications.

CreativeWork

URI https://schema.org/CreativeWork
Definition An intellectual or artistic result that arises from original effort or imagination.
Label CreativeWork

DateTime

URI http://www.w3.org/2001/XMLSchema#dateTime
Definition Empty
Label DateTime

Duration

URI http://www.w3.org/2006/time#Duration
Definition A measure of the time it takes to complete a specific task or activity, typically expressed in units such as seconds, minutes, or hours.
Label Duration
Parent http://www.w3.org/2006/time#TemporalEntity

Identifier

URI http://www.w3.org/ns/adms#Identifier
Definition Information used to uniquely identify an object.
Label Identifier
Usage note The starting point here is that this string is assigned by an organization and that this is done according to a specific system.

LangString

URI http://www.w3.org/1999/02/22-rdf-syntax-ns#langString
Definition Empty
Label LangString

Learning Activity Specification

URI http://data.europa.eu/snb/model/elm/LearningActivitySpecification
Definition The specification of a process that leads to the acquisition of knowledge, skills or responsibility and autonomy.
Label Learning Activity Specification
Usage note The training offer is formalized according to a certain specification, such as the ECTS. Both a course unit and a programme can be specified in this way.
Parent http://data.europa.eu/snb/model/elm/Specification

Learning ToolCollection

URI https://data.vlaanderen.be/ns/leermiddelen#LeermiddelVerzameling
Definition Collection of Educational Resources with the same characteristics.
Label Learning ToolCollection
Parent https://data.vlaanderen.be/ns/leermiddelen#Leermiddel

Learning activity

URI http://data.europa.eu/snb/model/elm/LearningActivity
Definition Any process that leads to the acquisition of knowledge, skills or responsibility and independence.
Label Learning activity
Usage note This entity contains the data points related to a learner's participation in a particular Learning Opportunity.
Parent http://data.europa.eu/snb/model/elm/Claim

Learning tool

URI https://data.vlaanderen.be/ns/leermiddelen#Leermiddel
Definition Any tool that is used to support the learning process, achieve goals and thus impart knowledge, skills and attitudes.
Label Learning tool
Usage note This definition is a specification based on the definition of the Quality Alliance, i.e.: The umbrella term for both paper and digital products, whether in combination or not, regardless of who develops them: teachers, non-commercial and commercial providers.
Parent https://schema.org/CreativeWork

License

URI https://schema.org/CreativeWork
Definition A formal permission or right to use, reproduce, or distribute something under certain conditions.
Label License
Parent https://schema.org/CreativeWork

Literal

URI http://www.w3.org/2000/01/rdf-schema#Literal
Definition Empty
Label Literal

Nourishment

URI http://data.europa.eu/m8g/Cost
Definition Empty
Label Nourishment

Period

URI http://www.w3.org/2006/time#ProperInterval
Definition Temporal Entity whose magnitude and duration is different from zero,ttz for which the start and end values are different.
Label Period
Parent http://www.w3.org/2006/time#TemporalEntity

Purpose

URI https://data.vlaanderen.be/ns/leermiddelen#Doel
Definition Description of what a learner needs to know, be able to do or what attitude they should have after completing a learning activity or training.
Label Purpose

Target audience

URI https://data.vlaanderen.be/ns/leermiddelen#Doelgroep
Definition A group of individuals with common characteristics, needs, or interests, to whom a Learning Tool or Goal is directed to effectively address their expectations.
Label Target audience

TemporeleEntiteit

URI http://www.w3.org/2006/time#TemporalEntity
Definition Empty
Label TemporeleEntiteit
