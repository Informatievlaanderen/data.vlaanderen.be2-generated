Classes

This section gives a formal definition to each class.

Agent

URI http://purl.org/dc/terms/Agent
Definition Iemand die of iets dat kan handelen of een effect kan teweeg brengen.
Label Agent

Competentie

URI https://data.vlaanderen.be/ns/leermiddelen#Competentie
Definition Een specifiek geheel van kennis, vaardigheden en attitudes die door een lerende moet worden beheerst.
Label Competentie
Usage note In deze context gaat het om sleutelcompetenties, wetenschapsdomeinen en beroepskwalificaties.

CreatiefWerk

URI https://schema.org/CreativeWork
Definition Een intellectueel of artistiek resultaat dat voorkomt uit originele inspanning of verbeelding.
Label CreatiefWerk

DateTime

URI http://www.w3.org/2001/XMLSchema#dateTime
Definition Empty
Label DateTime

Doel

URI https://data.vlaanderen.be/ns/leermiddelen#Doel
Definition Beschrijving van wat een lerende moet weten, kunnen of welke houding deze moet hebben na het voltooien van een leeractiviteit of opleiding.
Label Doel

Doelgroep

URI https://data.vlaanderen.be/ns/leermiddelen#Doelgroep
Definition Een groep van individuen met gezamenlijke kenmerken, behoeften of interesses, waarop een Leermiddel of Doel is gericht om effectief in te spelen op hun verwachtingen.
Label Doelgroep

Identificator

URI http://www.w3.org/ns/adms#Identifier
Definition Informatie gebruikt om een object uniek te identificeren.
Label Identificator
Usage note Uitgangspunt hier is dat deze string door een organisatie wordt toegekend en dat dit gebeurt volgens een welbepaald systeem.

Kost

URI http://data.europa.eu/m8g/Cost
Definition Empty
Label Kost

LangString

URI http://www.w3.org/1999/02/22-rdf-syntax-ns#langString
Definition Empty
Label LangString

Leeractiviteit

URI http://data.europa.eu/snb/model/elm/LearningActivity
Definition Elk proces dat leidt tot het verwerven van kennis,vaardigheden of verantwoordelijkheid en zelfstandigheid.
Label Leeractiviteit
Usage note Deze entitieit bevat de datapunten die te maken hebben met de deelname van een lerende aan een welbepaalde Leeropportuniteit.
Parent http://data.europa.eu/snb/model/elm/Claim

Leeractiviteitspecificatie

URI http://data.europa.eu/snb/model/elm/LearningActivitySpecification
Definition De specificatie van een proces dat leidt tot het verwerven van kennis,vaardigheden of verantwoordelijkheid en autonomie.
Label Leeractiviteitspecificatie
Usage note Het opleidingsaanbod geformaliseerd volgens een bepaalde specificatie,zoals de ECTS. Zowel een opleidingsonderdeel als een programma kunnen op deze manier gespecifieerd worden.
Parent http://data.europa.eu/snb/model/elm/Specification

Leermiddel

URI https://data.vlaanderen.be/ns/leermiddelen#Leermiddel
Definition Elk hulpmiddel dat wordt ingezet om het leerproces te ondersteunen, doelen te bereiken en zo kennis, vaardigheden en attitudes bij te brengen.
Label Leermiddel
Usage note Deze definitie is een specificatie gebaseerd op de definitie van de kwaliteitsalliantie, i.e.: Het overkoepelende begrip voor zowel papieren als digitale producten, al dan niet in combinatie, ongeacht wie ze ontwikkelt: leraren, niet-commerciële en commerciële aanbieders.
Parent https://schema.org/CreativeWork

LeermiddelVerzameling

URI https://data.vlaanderen.be/ns/leermiddelen#LeermiddelVerzameling
Definition Collectie van Leermiddelen met dezelfde kenmerken.
Label LeermiddelVerzameling
Parent https://data.vlaanderen.be/ns/leermiddelen#Leermiddel

Licentie

URI https://schema.org/CreativeWork
Definition Een formele toestemming of recht om iets te gebruiken, te reproduceren, of te verspreiden volgens bepaalde voorwaarden.
Label Licentie
Parent https://schema.org/CreativeWork

Literal

URI http://www.w3.org/2000/01/rdf-schema#Literal
Definition Empty
Label Literal

Periode

URI http://www.w3.org/2006/time#ProperInterval
Definition TemporeleEntiteit waarvan de omvang en duurtijd verschilt van nul,ttz waarvoor de begin- en eindwaarde verschillend zijn.
Label Periode
Parent http://www.w3.org/2006/time#TemporalEntity

TemporeleEntiteit

URI http://www.w3.org/2006/time#TemporalEntity
Definition Empty
Label TemporeleEntiteit

Tijdsduur

URI http://www.w3.org/2006/time#Duration
Definition Een maat voor de tijd die nodig is om een specifieke taak of activiteit te voltooien, doorgaans uitgedrukt in eenheden zoals seconden, minuten of uren.
Label Tijdsduur
Parent http://www.w3.org/2006/time#TemporalEntity
