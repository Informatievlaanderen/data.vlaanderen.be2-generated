Summary

The MAGDA Road Vignette Registrations Vocabulary contains the relevant terms to enable the data exchange of road vignette registrations according to a REST API on the MAGDA platform. The crucial class here is Road VignetteRegistrationEnvelope that links both road vignette registrations and MAGDA Exceptions.

Class Road vignette registration

Type Class
URI https://implementatie.data.vlaanderen.be/ns/magda/wegenvignetregistratie#Wegenvignetregistratie
Definition Registration of a Vehicle for a road vignette, which entitles the vehicle to use the road network for a certain period of time.
