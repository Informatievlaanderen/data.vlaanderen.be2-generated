This document describes a vocabulary, in this case Transport hubs. A vocabulary is a collection of reusable terms, namely classes and properties, whose meaning is recorded through a label and definition. For terms defined in this domain, additional formal agreements are available. For external terms, the formal agreements are copied from the external source.

Summary

The OSLO Transport Nodes vocabulary defines terms that are applicable to exchange data on Passenger Transport Nodes.

Class Hoppin point

Type Class
URI https://data.vlaanderen.be/ns/mobiliteit/vervoersknooppunten#Hoppinpunt
Specialization of
  • https://data.vlaanderen.be/ns/mobiliteit/vervoersknooppunten#GeregistreerdVervoersknooppunt
Definition Transport hub of the Hoppin mobility brand.

Usage

 Hoppin is the name under which the Flemish government designates Transport hubs for passenger transport that meet established (quality) requirements. Important matters are recognisability (application of the Hoppin house style), accessibility (for all users regardless of their disability, age, etc.), minimal equipment (e.g. bicycle sheds, information carriers, etc.), alignment with mobility plans, etc.

Class Transport hub

Type Class
URI https://data.vlaanderen.be/ns/mobiliteit/vervoersknooppunten#Vervoersknooppunt
Definition Place where passengers and/or cargo is exchanged between vehicles and/or modes of transport.

Usage

 Examples of passenger transport are train stations, metro stations, bus stations, airports, ferry terminals, car parks... For cargo transport, it typically involves airports, seaports, transshipment terminals. Transport hubs are typically intermodal, for example travellers combine the (shared) bicycle with the train for their journey, but intramodal transfers (for example from one bus line to another) are also important. In concrete terms, a Transport Hub includes infrastructure (stations, car parks, charging infrastructure, etc.), (mobility) services (public transport lines, shared bicycles, shops, etc.) and nodes in transport networks (public transport stops, shared car stations, etc.).

Class Virtual Node

Type Class
URI https://data.vlaanderen.be/ns/mobiliteit/vervoersknooppunten#VirtueleKnoop
Specialization of
  • https://data.vlaanderen.be/ns/transportnetwerk#Transportknoop
Definition Transport node that is dynamically created.

Usage

 The place where a Journey is started usually does not coincide with an existing Transport Node, for example it is the Traveller's home located between two intersections. In order to still enter the network to start his Journey, the Traveler creates a Virtual Node on the link between these intersections. Virtual Nodes are important to make a correct estimate of the travel time, for example in route planning, because the distance between the Virtual Node and the next real Transport Node must be added. Also important, for example, in the case of free-floating shared transport where the position of, for example, the shared scooter does not necessarily coincide with that of an existing Transport Node.

6. External terminology

Since 2025, external terms are no longer included as non-normative mapping in vocabularies of data.vlaanderen.be.

Instead, a table with which external URIs are used has been added to each application profile. This simplifies the objective of this document. Namely listing and managing terms defined in this namespace.

To still achieve harmonization of the use of external terminology, a general mapping is published.
