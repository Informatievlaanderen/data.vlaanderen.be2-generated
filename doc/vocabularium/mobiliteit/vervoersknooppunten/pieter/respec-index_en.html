Transport hub

URI https://data.vlaanderen.be/ns/mobiliteit/vervoersknooppunten#Vervoersknooppunt
Definition Place where passengers and/or cargo is exchanged between vehicles and/or modes of transport.
Label Transport hub
Usage note Examples of passenger transport are train stations, metro stations, bus stations, airports, ferry terminals, car parks... For cargo transport, it typically involves airports, seaports, transshipment terminals. Transport hubs are typically intermodal, for example travellers combine the (shared) bicycle with the train for their journey, but intramodal transfers (for example from one bus line to another) are also important. In concrete terms, a Transport Hub includes infrastructure (stations, car parks, charging infrastructure, etc.), (mobility) services (public transport lines, shared bicycles, shops, etc.) and nodes in transport networks (public transport stops, shared car stations, etc.).

Virtual Node

URI https://data.vlaanderen.be/ns/mobiliteit/vervoersknooppunten#VirtueleKnoop
Definition Transport node that is dynamically created.
Label Virtual Node
Usage note The place where a Journey is started usually does not coincide with an existing Transport Node, for example it is the Traveller's home located between two intersections. In order to still enter the network to start his Journey, the Traveler creates a Virtual Node on the link between these intersections. Virtual Nodes are important to make a correct estimate of the travel time, for example in route planning, because the distance between the Virtual Node and the next real Transport Node must be added. Also important, for example, in the case of free-floating shared transport where the position of, for example, the shared scooter does not necessarily coincide with that of an existing Transport Node.
Parent https://data.vlaanderen.be/ns/transportnetwerk#Transportknoop
