URI https://data.vlaanderen.be/ns/openbaardomein/gebied#Begraafplaats

Bufferzone

Label Bufferzone
Parent https://data.vlaanderen.be/ns/openbaardomein/gebied#Gebied

Gebied

URI https://data.vlaanderen.be/ns/openbaardomein/gebied#Gebied
Definition Een ruimte met daarin objecten in de openbare ruimte die samen een hoofdfunctie hebben.
Label Gebied
Usage note De openbare ruimte wordt geïnterpreteerd zoals aangegeven in het GRB lexicon (Informatie Vlaanderen): "Ruimte die ten dienste staat van iedereen (algemeen belang), zonder beperking naar specifieke gemeenschappen. De openbare ruimte is principieel voor iedereen toegankelijk". Voorbeeld: een stadspark is parkzone, om hiermee aan te duiden dat de zone is ontworpen is om recreatie en natuur samen te laten plaatsvinden.

Groenzone

Park

URI https://data.vlaanderen.be/ns/openbaardomein/gebied#Park
Definition Een gebied dat meerdere functies combineert, waaronder hoofdzakelijk recreatieve en ecologische functies.
Label Park
Usage note Indien een verdere detaillering van parken gewenst is, bijvoorbeeld op basis van hun oppervlakte, kan gekeken worden naar de drempelwaarden voor stedelijk groen zoals gedefinieerd in het Milieurapport Vlaanderen (MIRA).
Parent https://data.vlaanderen.be/ns/openbaardomein/gebied#Gebied

Parking

URI https://data.vlaanderen.be/ns/openbaardomein/gebied#Parking
Definition Hoofdzakelijk buiten de rijbaan gelegen zone, bedoeld voor het langdurig laten stilstaan van een voertuig in parkeervakken, inclusief de gemeenschappelijk gebruikte ruimte van de zone die buiten de parkeervakken.
Label Parking
Parent https://data.vlaanderen.be/ns/openbaardomein/gebied#Gebied

Plein

URI https://data.vlaanderen.be/ns/openbaardomein/gebied#Plein
Definition Een onbebouwde en openbare ruimte, typisch omgeven door gebouwen, dat deel uitmaakt van het stratennet van een stad of gemeente.
Label Plein
Usage note Op een plein kunnen diverse activiteiten doorgaan, in aanvulling op de verkeersfunctie.
Parent https://data.vlaanderen.be/ns/openbaardomein/gebied#Gebied

Recreatiegebied

Parent https://data.vlaanderen.be/ns/openbaardomein/gebied#Gebied

Recyclagepark

Spoorweg

Tuinzone

Definition Gebied ingericht en/of beheerd als openbare tuin, meestal aanliggend aan gebouwen voor algemeen nut (scholen, jeugdlokalen, religieuze gebouwen, cultuurcentra, politie, brandweer, etc.)
Label Tuinzone
Parent https://data.vlaanderen.be/ns/openbaardomein/gebied#Gebied

Volkstuin

URI https://data.vlaanderen.be/ns/openbaardomein/gebied#Volkstuin

Label Volkstuin
Parent https://data.vlaanderen.be/ns/openbaardomein/gebied#Gebied

Waterverkeerzone

Definition Gebied bedoeld om hoofdzakelijk transport via waterwegen te kunnen laten plaatsvinden, inclusief de gebieden die wezenlijk deel uitmaken van de waterwegen (vb: oevers).

Parent https://data.vlaanderen.be/ns/openbaardomein/gebied#Gebied

Wegzone
